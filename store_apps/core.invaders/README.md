# Space Invaders

Hold off descending waves of aliens.

A playable Assistant Matrix game plugin. Control layout: `horizontal`.

Actions: `left`, `right`, `fire`, `pause`, `resume`, `togglePause`, `restart`

Install it from the Store, or package it yourself with:

```bash
poetry run assistant-matrix-app validate app.toml
poetry run assistant-matrix-app package . --output-dir dist
```
