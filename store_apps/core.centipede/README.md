# Centipede

Shoot it apart before it reaches you. Every hit leaves a mushroom.

A playable Assistant Matrix game plugin. Control layout: `dpad`.

Actions: `left`, `right`, `up`, `down`, `fire`, `pause`, `resume`, `togglePause`, `restart`

Install it from the Store, or package it yourself with:

```bash
poetry run assistant-matrix-app validate app.toml
poetry run assistant-matrix-app package . --output-dir dist
```
