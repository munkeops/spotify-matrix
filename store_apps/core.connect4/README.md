# Connect Four

Line up four discs before your rival does.

A playable Assistant Matrix game app. Control layout: `horizontal`.

Actions: `left`, `right`, `drop`, `pause`, `resume`, `togglePause`, `restart`

Install it from the Store, or package it yourself with:

```bash
poetry run assistant-matrix-app validate app.toml
poetry run assistant-matrix-app package . --output-dir dist
```
