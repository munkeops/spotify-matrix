# Connect Four

Line up four discs before your rival does.

A playable Assistant Matrix game plugin. Control layout: `horizontal`.

Actions: `left`, `right`, `drop`, `pause`, `resume`, `togglePause`, `restart`

Install it from the Store, or package it yourself with:

```bash
poetry run assistant-matrix-widget validate widget.toml
poetry run assistant-matrix-widget package . --output-dir dist
```
